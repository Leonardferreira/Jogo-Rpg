Compartilhar com vocês meu mais recente projeto: 
um sistema de combate RPG totalmente desenvolvido do zero com Java e os 
principais conceitos de Programação Orientada a Objetos! 🎮🛡️

No projeto, criamos a classe base Personagem, que deu origem às subclasses Herói e Monstro, 
com comportamentos e características específicas. 🧙‍♂️👹

Implementamos um sistema de turnos que trouxe muita estratégia ao jogo:
⚔️ Ataques Especiais com 50% de chance de sucesso
🛡️ Defesa Inteligente para bloquear ataques
💊 Uso de Poções de Vida para momentos críticos

Foi uma experiência incrível aplicar herança, polimorfismo, encapsulamento e abstração 
para construir um sistema robusto e divertido.
